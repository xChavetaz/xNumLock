# Política de Seguridad

## Versiones soportadas

Las correcciones de seguridad se aplican únicamente sobre la última versión publicada en la rama principal:

| Versión | Soportada |
| :--- | :--- |
| Última release / `main` | Sí |
| Versiones anteriores | No |

## Cómo reportar una vulnerabilidad

**Por favor, no publiques vulnerabilidades de seguridad en Issues públicos ni en Discussions.**

Si detectas un fallo de seguridad:

- Utiliza la opción **"Report a vulnerability"** en la pestaña [Security](../../security/advisories) de este repositorio.

Intentaré revisar el reporte y responder lo antes posible dentro de mi disponibilidad.
