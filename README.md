## Description
Application for windows that allows to have the numerical keypad activated all the time, if by mistake the numerical keyboard is deactivated, it is activated again instantly. It is ideal for people who use the numeric keypad to enter numbers.

The ulitity remains active in the taskbar all the time (it must be added to the windows startup programs). It has a small menu that allows to visualize the status of the function and allows to activate or deactivate it.
