# Guía de participación

¡Gracias por tu interés en este proyecto! Este repositorio está desarrollado y mantenido en solitario, por lo que seguimos unas pautas sencillas para mantener el proyecto manejable.

## Cómo puedes ayudar

- **Reportar fallos (Bugs):** Si encuentras un error, abre un *Issue* indicando tu entorno, versión del proyecto, pasos para reproducirlo y los registros (*logs*) relevantes.
- **Proponer mejoras:** Puedes abrir un *Issue* describiendo el caso de uso y por qué sería útil.
- **Consultas y soporte:** Para preguntas de configuración o uso, utiliza la sección **Discussions** en lugar de abrir un *Issue*.

## Política sobre Pull Requests

Actualmente **no se aceptan Pull Requests externos** con nuevas funcionalidades o cambios estructurales, ya que no dispongo de tiempo para revisar y mantener código de terceros a largo plazo.

Si deseas adaptar el proyecto a tus propias necesidades, eres libre de hacer un **fork** conforme a los términos de la licencia del repositorio.

> **Nota:** Si detectas una errata menor en la documentación, puedes mencionarlo en un *Issue* para corregirlo en la siguiente revisión.
